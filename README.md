# 📚 دحيح أوفلاين (Daheeh Offline)
### تطبيق الذكاء الاصطناعي والمساعد التعليمي الأوفلاين 100% لطلاب الثانوية العامة المصرية 🇪🇬

> **تم إنشاء وتطوير هذا التطبيق بواسطة المطور: مُحمد مفرح**

---

## 🌟 نظرة عامة (Overview)

تطبيق **دحيح أوفلاين** هو منصة تعليمية ذكية ومتكاملة تعمل محلياً على جهاز الطالب بنسبة **100% Offline** بدون الحاجة لأي اتصال بالإنترنت، ولا يعتمد على أي خوادم خارجية أو واجهات سحابية. 

صُمم التطبيق خصيصاً لطلاب **الثانوية العامة المصرية** ليقدم تجربة مذاكرة، استفسار، تلخيص، وحل امتحانات تفاعلية مع توثيق صارم من كتب ومذكرات الطالب الخاصة بصيغة PDF.

## 🏗️ الهيكلية التقنية (Architecture & Engines)

```
                       📱 Android Application (Jetpack Compose / M3)
                                            │
               ┌────────────────────────────┼────────────────────────────┐
               ▼                            ▼                            ▼
      🧠 Local AI Engine           🎙️ Local STT Engine          📷 Local OCR Engine
   (Qwen 2.5 GGUF / llama.cpp)     (Whisper / whisper.cpp)      (Tesseract / ara.traineddata)
               │                            │                            │
               └────────────────────────────┼────────────────────────────┘
                                            ▼
                           🗄️ AppRepository & Room SQLite
                                            │
               ┌────────────────────────────┴────────────────────────────┐
               ▼                                                         ▼
     📚 Flexible PDF Library (1-10)                          📝 Advanced Exam Engine
     (PdfExtractor + Inverted Index)                         (MCQs + Essays + Mistakes Notebook)
```

1. **🧠 محرك الاستدلال اللغوي المحلي (Qwen GGUF / llama.cpp):**
   - استيعاب ملفات النماذج المضغوطة `qwen2.5-0.5b-instruct-q4_k_m.gguf`.
   - قراءة الـ Header ومعاينة الـ Tensors وبيانات GGUF الوصفية (Metadata).
   - استدلال لغوي صارم مقيد فقط بالسياق المستخرج من كتب الـ PDF المرفقة.
   - إذا لم ترد المعلومة في ملفات الطالب يرجع النص الصارم: `لم أجد إجابة لهذا السؤال في ملفاتك.`

2. **🎙️ محرك تحويل الصوت إلى نص (Whisper / whisper.cpp):**
   - استيراد نموذج `ggml-tiny.bin` لتفريغ الصوت العربي محلياً بدقة 16kHz PCM.
   - شريط إدخال ذكي يدمج الصوت، الصورة، والنص في مساحة موحدة.

3. **📷 محرك التعرف الضوئي على الحروف (Tesseract Arabic OCR):**
   - استيراد ملف القاموس العربي `ara.traineddata`.
   - معالجة الصور (Binarization, Contrast, Sharpening) واستخراج النصوص العربية من صفحات الكتب المصورة.

4. **📚 مكتبة ملفات الـ PDF المرنة (Flexible 1-10 Slots):**
   - دعم كامل من 1 حتى 10 ملفات PDF.
   - رفض قاطع واستجابة واضحة عند محاولة تجاوز الحد الأقصى (10 ملفات).
   - بناء فهرس معكوس (Inverted Index) محلي بالكامل على Room SQLite مع حساب أوزان BM25 وتطبيع الحروف العربية وإزالة علامات التشكيل والزوائد اللغوية (Light Stemming).

5. **📝 محرك الامتحانات ونظام التشخيص العلاجي:**
   - توليد امتحانات قابلة للتخصيص: درس واحد، وحدة، وحدتان، المنهج كامل، أو ملف PDF محدد.
   - أسئلة اختيار من متعدد (4 خيارات بالضبط) وأسئلة مقالية.
   - مؤقت زمني دقيق لكل اختبار مع حفظ الإجابات محلياً.
   - دفتر الأخطاء التلقائي وإعادة الاختبار العلاجي للأخطاء السابقة فقط.
   - تحليل بياني دقيق لمستوى الإتقان، السرعة، ونقاط القوة والضعف.

## 📥 دليل استيراد النماذج محلياً (Local Models Import Guide)

بعد تثبيت الـ APK على الهاتف، توجه إلى شاشة **«إدارة النماذج» (Settings)** لاستيراد الملفات الثلاثة مباشرة من ذاكرة جهازك:

| اسم النموذج | نوع النموذج | الوظيفة | الامتداد المقبول |
| :--- | :--- | :--- | :--- |
| **qwen2.5-0.5b-instruct-q4_k_m.gguf** | ذكاء اصطناعي (LLM) | الإجابة الصارمة من كتب المنهج وتوليد الشروحات | `.gguf` |
| **ggml-tiny.bin** | صوت إلى نص (STT) | تفريغ الأسئلة الصوتية باللغة العربية | `.bin` |
| **ara.traineddata** | التعرف الضوئي (OCR) | قراءة واستخراج النصوص من صور الكاميرا | `.traineddata` |

### خطوات الاستيراد:
1. افتح شاشة **إدارة النماذج**.
2. اضغط على زر **استيراد نموذج جديد (+)**.
3. اختر نوع الملف واضغط على **تحديد الملف من الهاتف**.
4. سيتم فحص صيغة الملف وحفظه بأمان داخل المسار الخاص بالتطبيق `context.filesDir/models/`.
5. يمكنك الضغط على **فحص واختبار** للتحقق من سلامة النموذج وجاهزيته.

## 🛠️ متطلبات البناء والتجميع (Build Requirements)

- **Android Studio / Gradle (Kotlin DSL)**
- **Target SDK**: Android 15 (API 35)
- **Min SDK**: Android 8.0 (API 26)
- **UI Toolkit**: Jetpack Compose مع Material Design 3
- **Local Persistence**: Room Database 2.6.1 مع KSP
- **Architecture**: Clean Architecture / MVVM

### أوامر البناء:
```bash
# تجميع نسخة الـ Debug
gradle assembleDebug

# تشغيل الاختبارات المحلية
gradle :app:testDebugUnitTest
```

- التطبيق **لا يطلب صلاحية الإنترنت** (`android.permission.INTERNET` غير موجودة في الـ Manifest).
